# Agent Examples

*This is not an officially supported Google product*

This repository houses code samples for content at
https://wdenniss.com/ap

To run the samples:

1. Authenticate gcloud (`gcloud auth login`)
2. Create an account at [Alpaca](alpaca.markets), and create a `.env` file
   in the project root directory with your Alpaca API keys:

```
# Alpaca Paper Trading Keys
APCA_API_KEY_ID=your-key-id
APCA_API_SECRET_KEY=your-key
```

3. See the individual README.md files and the blog posts
   for how to deploy.
